快速开始

猛人学习把本地的课程视频、音频和书籍、文档整理成可以放进 Obsidian 知识库的笔记。第一次使用按下面四步来：

  1. 设置 AI 服务：点右上角的齿轮打开「设置」。
    • 中文课程的字幕识别：填「豆包语音」的 API Key（或「硅基流动」）。
    • 英文课程的字幕识别：填「OpenAI」的 API Key。
    • 校对、课程重点、画面识别、书籍整理：用 ChatGPT 账号登录最省事（不另花 API 费用）；也可以填 Claude、Gemini、DeepSeek 等的 Key。
    • 每个服务都有「测试连接」按钮，填好点一下确认能用。
  2. 选 Obsidian 库：「设置 → Obsidian」里选库的位置和存放的文件夹。
  3. 建老师档案：「设置 → 老师与术语表」给常听的老师建一份术语表，推荐直接关联 Obsidian 里的术语表文件。
  4. 加课程：左边媒体库点「＋文件夹」，把课程文件夹加进来，点哪个看哪个；再点顶栏的「一键整理」。

看不懂某个按钮时，把鼠标停在上面一会儿，会出现说明。

界面上的标签和按钮

鼠标停在大多数按钮和标签上，也会显示一句说明。

媒体库（左边）

  • 上方三个按钮：添加文件夹（包括子文件夹里的音视频和文档）、添加单个文件、刷新（在电脑上新增或改了文件后点一下）。下面的「筛选文件名」框：输入几个字，只显示名字（或所在文件夹名）里有这几个字的。
  • 文件前面的小圆点：灰色 = 还什么都没做；绿色 = 已经有字幕（书是整理了至少一章）；金色 = 已剪藏到 Obsidian，而且之后没改过。
  • 字幕 582 句：这节课的字幕有多少句。
  • 重点：已经有课程重点。
  • 重点待更新：生成课程重点之后，你又改了 3 句以上字幕，重点里可能还是改之前的说法。打开这节课，在课程重点上方点「重新生成」。
  • 未整理完：已经有课程重点（书是每章都整理完了），但「一键整理」默认的步骤还没全做完，常见的是写完重点后 AI 额度用完，「查漏补缺」「新术语」没做成。鼠标停在标签上能看到还差哪几步。再点一次「一键整理」，或右键选「排进后台整理」，只会补做没做完的那几步，做过的不重复做、不重复花钱。
  • 已校对：你在字幕栏上方打开了「已校对」开关（人工检查过字幕）。
  • 已剪藏：已经剪藏到 Obsidian，笔记和软件里的内容一致。待更新剪藏：剪藏之后又改了字幕或课程重点，再点一次「剪藏」，Obsidian 里的笔记才会更新。
  • 整理中 45% / 排队中：这节课正在后台整理 / 排在后台整理队列里，等前面的整理完。
  • 看到 12:30 和下面的细进度条：上次看到哪里，再打开从这里接着播。
  • 整理 2/5（书籍）：一共 5 章，整理了 2 章。
  • 右键或「⋯」：文件可以打开、排进后台整理、重命名、在资源管理器中显示；文件夹可以绑定老师（术语表）、重命名、重新扫描、在资源管理器中打开；最上层的还可以从媒体库移除（不删除电脑上的文件）。
  • 按住拖动：在同一层里调整顺序。带序号的按序号排，拖乱了序号会请你改名。

字幕（右边）和视频下方

  • 视频下方的开关：字幕跟随（播放时字幕自动滚到当前句）、译文（显示中文译文）、画面字幕（在视频画面上叠加当前字幕）、单句循环（反复播放当前这一句，开着时旁边写着在循环哪一句，点一下就关）。最右边是播放速度。
  • 搜索字幕：输入后按 Enter 跳到下一处，旁边显示一共找到几处。
  • 存疑 5（有存疑句时才出现）：AI 校对时拿不准的句子还剩几句，点一下跳到下一句并单句循环播放，方便回听。
  • 已校对开关：你人工检查完字幕后打开，剪藏的笔记里会标注「已人工校对」，媒体库也标「已校对」。旁边的「582 句」是字幕句数。
  • Aa：字号、行距、句间距、宽度、字体、配色主题。
  • 时钟图标（历史版本）：重新识别、AI 校对、清空、恢复之前自动存的旧字幕（最多 5 份），可以恢复；也可以在这里清空字幕。
  • 弯箭头（撤销）：撤销拆分、合并、删除、校对（Ctrl + Z）。
  • 每一句上的标记：橙色下划线 = 存疑句，下面写着原因，有「回听」（单句循环播放这一句）和「已确认」（回听确认或改好了，去掉标记）两个按钮；绿色下划线 = 刚被 AI 校对或画面复核改过的句子（方便你看改了哪里，可以撤销）；高亮的那一句 = 正在播放。
  • 鼠标移到某一句，右边出现四个小工具：对齐（把这一句的开始时间设为当前播放位置）、拆分（在光标处拆成两句）、合并（和下一句合并）、删除。
  • 点时间只跳转；点文字跳转并可以直接改，改完自动保存。

课程重点（AI 区）

  • 三个标签页：课程重点、AI 对话（就这节课提问）、画面（挑出来的插图，数字是有几张）。
  • 朗读（耳机图标）：边听边看。课程重点页读课程重点，AI 对话页读 AI 的回答；中括号里的时间（如 [01:50]）、插图、流程图不读，开始时视频自动暂停。正在读的句子高亮，快读到底部时自动往下翻；自己用滚轮滚动后暂停跟随，停手 6 秒自动恢复，点「定位」马上回来。双击任意一句，从这一句开始读（没在朗读时也直接开始）；双击正在读的那一句暂停 / 继续。播放条上有上一句、下一句、语速（0.75×～2×）、声音、更多（从头朗读、从当前屏幕开始、高亮颜色）。下次再点朗读，从上次读到的地方接着读。
    声音有三种来源：Edge 在线朗读（默认，声音最自然，晓晓、云希等，要联网）、百度朗读（要联网，正在读的句子会发给百度翻译；不是百度正式开放的服务，百度改了就会失效）、系统声音（Windows 自带的慧慧、瑶瑶、康康，不联网）。在线声音没取到时自动重试，还不行就停在这一句并告诉你。会提前准备后面几句；在线声音某一句回得慢时会自动再要一次。声音只在内存里，不占硬盘。
  • 右上角：写着现在用的是哪个 AI 和模型；三个小按钮分别是放大 AI 区（视频缩到最小）、移到右侧 / 移回视频下方、隐藏 AI 区。
  • 「生成课程重点之后，字幕又改了 N 句」提醒条：同媒体库的「重点待更新」，点里面的「重新生成」用改好的字幕重写（会自动查漏补缺）。
  • 生成课程重点 / 重新生成：按这节课的完整字幕写课程重点，写完默认自动查漏补缺。
  • 查漏补缺：对照完整字幕，找出课程重点漏掉的内容，补进对应的小节。
  • 新术语：找出这节课里术语表还没有的新术语和识别错误，你勾选确认后才加进老师的术语表。按钮变亮表示已经找好了、等你勾选。
  • 编辑：直接改课程重点。复制：复制全文。
  • 插入截图（视频才有）：把视频现在的画面截下来，插在出处时间离现在最近（不晚于现在）的那一条重点后面；正在「编辑」时插在光标那一行后面。图下面「上移 / 下移」一次挪过一条重点（标题、一张表也算一条），「删除」去掉这张图；AI 插的图也能这样挪。手动插的图「重新生成」课程重点后会自动放回去；剪藏时和 AI 插的图一样放进笔记。
  • ✂ 裁剪（课程重点和字幕栏的截图下面都有）：在截图上拖出要留下的部分（框还是整张时直接拖就是画框；画好后拖框里面移动，拖四角、四边调整），「整张（不裁剪）」恢复整张图。原截图不会被改。
  • ⇲ 大小（同上）：拖滑块调这张图显示多宽，图马上跟着变，不用点确定；也可以点「小 / 中 / 大 / 自动」（自动 = 原来的大小）；「这节课的图都用这个大小」把课程重点和字幕栏里这节课的截图都改成一样大。软件里、打印出来、剪藏到 Obsidian 的笔记里都是这个大小。
  • 打印（朗读旁边，课程重点页才有）：只打印课程名和课程重点（连同插图），文字黑色，图片保持原色；在弹出的打印窗口里「颜色」选「彩色」就打印彩色图片，选「黑白」省彩色墨水；也可以选「另存为 PDF」。
  • 下面那行小字：「字幕被引用约 93%」是课程重点里标了出处时间的内容，覆盖了多少字幕；「有 3 段没有出处（如 00:06…）」是哪几段字幕没被重点引用，可以点时间回去听听有没有漏掉要紧的。
  • 重点里带方括号的时间（如 [01:42]）点一下跳到视频那里。

媒体库

  • ＋文件夹：一次加入整个文件夹，按实际层级显示，每一层子文件夹都能展开、收起。识别视频、音频和文档（PDF、Word .docx / .doc、电子书 EPUB / MOBI / AZW3、演示文稿 PPT / PPTX）；字幕、txt、软件自己的记录文件不列。名字以「_」或「.」开头的文件夹（比如「_关键帧缓存」）不列出。选文件夹的窗口里只显示文件夹、看不到文件是正常的，选中点「选择文件夹」就行，加完会告诉你加了几个、跳过了哪些格式。
  • 先加了子文件夹、又加它的上层：会问你要不要合并。合并就按实际层级显示，原来单独加的并进来（绑定的老师、排好的顺序都保留）；不合并就重复加入，子文件夹会出现两次。上层已经在了再加子文件夹，会提示「已经在里面了」。
  • ＋文件：加入单个文件，和文件夹一起按加入的先后排在最上层。TXT 和 Markdown 用顶栏的「打开」。
  • 排列：最上层按加入的先后；文件夹里同一层，带序号的（1、 01. 第3讲）按序号排在前面，没序号的按下载时间排在后面。按住拖动可以在同一层里调整顺序；带序号的拖乱了序号，会提示你改名（改序号），改完自动按序号排好。
  • 重命名（右键或「⋯」菜单）：电脑上的文件 / 文件夹、字幕记录、播放进度一起改名。已经剪藏到 Obsidian 的笔记保留原来的文件名，重新剪藏也不改（Obsidian 里其他笔记的链接不会断）。
  • 状态标记（字幕句数、重点、重点待更新、未整理完、已校对、已剪藏、待更新剪藏、整理中、排队中、看到哪里、整理几章）：每个是什么意思，见「界面上的标签和按钮」。
  • 文件夹的「⋯」菜单：每一层文件夹都能绑定一位老师，里面的课用这位老师的术语表；子文件夹没单独绑定的，沿用上一层的。还可以重命名、重新扫描、在资源管理器中打开，最上层的可以从媒体库移除（不会删除电脑上的文件）。
  • 顶栏最左边的按钮可以收起 / 展开媒体库，拖动媒体库右边的分隔条可以调宽度。
  • 续播：每个视频都记住看到哪里，再打开时从上次的位置接着播。

生成字幕

  1. 打开视频，点顶栏的「生成字幕」。
  2. 选视频里说的是中文还是英文、是哪位老师的课（决定用哪份术语表）、用哪个识别服务。
  3. 勾选「识别完后让 AI 按术语表校对一遍」可以自动接着校对。
  • 豆包语音（中文最准）：带逐句时间；术语会作为热词传给豆包。按「流式识别 2.0 → 录音文件识别 1.0 极速版 → 录音文件识别 2.0」的顺序自动用，额度用完自动换下一个；可以在「设置 → 豆包语音」里填好几个账号。
  • OpenAI Whisper（英文）：带逐句时间；术语写进提示词。国内要在「设置 → 网络代理」里填代理。
  • 硅基流动：便宜，但只返回文字不返回时间，软件按停顿切段，时间可能差几秒；读不了术语表，靠后面的 AI 校对。
  • 软件先用 ffmpeg 从视频里抽出声音（只上传声音，不上传画面），长视频在停顿处切段、几段同时识别，再拼回去。
  • 已经有字幕时重新识别，原来的字幕会自动存成历史版本，可以换回来。

老师与术语表

在「设置 → 老师与术语表」里给每位老师建一份档案；在顶栏的老师下拉框里选这节课是哪位老师的。

  • 关联 Obsidian 里的术语表文件（推荐）：选中知识库里那份术语表 MD，软件每次都读最新内容——小节里「正确写法 / 标准写法」的词和 --hotwords "…" 里的词当术语，表头含「ASR / 误识 / 识别」的表格当识别错误参考，整份文件给 AI 当术语说明。以后只在 Obsidian 里改。软件不把文件里的术语抄进下面的「术语表（手写）」框：那个框只用来额外手写几个，空着是正常的。关联后下面有两个按钮：查看术语和重复检查（看软件从文件里读到的每个术语、识别错误对照、直接替换；同一个术语或同一条「错写 → 正确」在文件里出现不止一次的，列出在第几行，想清理就去 Obsidian 删掉多余的那行，软件读的时候本来就只算一次）、在 Obsidian 里打开（直接打开这份术语表手动修改）。
  • 不会重复加：每节课找新术语时，术语表里已有的（整份文件任何一张表里有的）不会再列出来；几节课一起在后台整理、再一节节勾选时，前面的课已经加过的，打开对话框时会先去掉；写进文件前也会再查一遍整份文件。
  • 手写术语表（可选，和关联的文件合在一起用），每行一条：
    • 峰级, 峰级线, 破级：专用术语，传给识别服务当热词；
    • 风级, 风机 => 峰级：常见识别错误，交给 AI 结合上下文判断，不直接替换；
    • 托破旋 =>! 拓扑学：确定不会误伤的，识别完直接替换。单字或常用词不要加感叹号，否则「部分」会被改成「部峰」。
  • 逐课积累：AI 区「课程重点」页的「新术语」按钮（一键整理的最后一步也会做）：AI 从这节课的校对改动（AI 改的、看画面改的、你手动改的）和完整字幕里，找出术语表还没有的新术语和识别错误，弹出来让你勾选、改字、点时间回听；确认的才加进去。关联了文件时写在文件末尾的「逐课补充（猛人学习）」一节（表格，软件下次就会用上），写之前自动备份到 %APPDATA%\猛人学习\backups\术语表；只记名称，不写定义。
  • 新老师的第一节课：还没有这位老师、也没有术语表时，同样点「新术语」（或一键整理勾上「新术语」，没选老师时默认勾上）。AI 找出这节课的专用术语，弹出来让你勾选，再填老师名字、选「以后哪个文件夹里的课都用这位老师」（默认是加进媒体库的那个文件夹），点「建立术语表」：软件建好老师档案，在 Obsidian「02、规则体系/02、课程专用规则」里建一份「老师名课程术语表」（结构和峰级那份一样：怎么用 / 术语 / 识别错误对照 / 逐课补充），关联上，把勾选的写进「逐课补充」，并把那个文件夹绑定这位老师。以后这个文件夹里的课自动用这位老师：识别时用这些术语当热词，每节课整理完接着找新术语让你勾选。填的名字和已有的老师一样时，就加进他原来的术语表。
  • 术语说明：放整份术语说明文档，只给 AI 参考，不传给识别服务。关联了文件时一般留空。
  • 剪藏笔记里不写老师：一份术语表常常是几位老师共用的（例如「峰级分析」），它的名字只当笔记的标签。讲课老师请在 Obsidian 里给笔记加一个「老师」属性自己填，重新剪藏会保留。
  • 剪藏子文件夹、单独的课程重点模板：可选。

看字幕、改字幕

  • 点字幕文字：跳到这一句，同时可以直接修改，改完自动保存。点时间：只跳转。
  • 鼠标移到某一句，右侧有工具：把开始时间对齐到当前播放位置、在光标处拆成两句、与下一句合并、删除。都可以撤销（Ctrl + Z 或字幕栏上方的撤销按钮）。
  • 字幕栏上方：搜索（Enter 跳到下一个）、「插入截图」（把视频现在的画面插在正在播放的这一句后面；断句不准时点图下面的「上移 / 下移」挪位置，「✂ 裁剪」只留需要的部分，「⇲ 大小」调图显示多大，用法和课程重点的截图一样；剪藏时也放进笔记的「完整字幕」）、「已校对」开关（人工检查完打开，剪藏的笔记会标明）、「Aa」文字设置（字号、行距、句间距、宽度、字体、主题）、历史版本（重新识别、AI 校对、清空、恢复前自动存的，最多 5 份）。
  • 视频下方：字幕跟随、显示译文、画面上叠加字幕、单句循环（开着时旁边写明在循环哪一句，点一下就关；换一节课自动关掉）、播放速度。
  • 布局：视频和字幕之间、视频和 AI 区之间的分隔条都能拖动；AI 区可以移到最右边当侧边栏、放大或隐藏。

AI 校对和存疑句

  • 点顶栏的「AI 校对」：AI 参考术语表、识别错误对照和术语说明，只改识别错误（错别字、同音词、术语、人名、数字），不改写句子。
  • 改过的句子用绿色下划线标出，不满意可以撤销；校对前的字幕也会存一份历史版本，关掉软件后还能恢复。
  • 校对到一半出错（网络断了、AI 返回不对），字幕一句都不改，保持原样，可以直接再点一次。
  • 存疑句：读起来不通、像是听错了、但 AI 拿不准的句子，不会乱改，而是用橙色标出并写明原因。点字幕栏上方的「存疑 N」逐句跳过去，会单句循环播放方便回听；改好或确认没问题后点「已确认」。剪藏的笔记里，没确认的存疑句会标「〔存疑：…〕」。

插图（画面）

AI 区的「画面」页，用来给课程重点挑必要的插图：只有光看文字不好理解的地方才插图，笔记尽量小。需要能看图的 AI（「设置 → 任务用哪个 AI → 画面识别」）。

  • 找插图：软件每隔约 15 秒截一张候选画面（避开老师挡住屏幕的那几秒），老师说「大家请看」时也截一张；AI 只留需要看图才好理解的（走势图、K 线标注、老师手画的曲线和结构图），纯文字课件、标题页都不要；每张写一句说明，告诉课程重点该插在哪里。
  • 截取当前画面：看到重要画面时手动加一张。
  • 用画面复核存疑句：AI 校对后还拿不准的句子，软件截下每句说话时的画面（课程画面底部常有烧录字幕，课件、板书上也可能有这个词），交给 AI：能确认的直接改正（绿色下划线），看不清的继续存疑，留给你回听。一键整理里会自动做。
  • 说明可以自己改；去掉「可插图」的勾，课程重点就不会插这张；点缩略图看大图。
  • AI辅助理解图：要插的图如果画面本身看不清（PPT、板书模糊或被挡住），AI 会依据老师的讲解和画面里能看清的部分重画一张：结构、流程类画成流程图，走势、K 线、曲线类画成矢量图；剪藏时代替截图，并标注「AI辅助理解图｜根据老师讲解和画面整理，非原画面」。只画老师讲过、画过的，拿不准就不画。也可以在画面页对某张图点「AI 重画」；不满意点「改用原截图」。
  • 课程重点只在文字确实说不清的地方插图，整节课最多 3 张；剪藏时图片缩小压缩，复制到笔记旁边的 image 文件夹。
  • 插图非必要不用：只有文字确实说不清的（手绘曲线的形状、K 线标注的位置、复杂结构图）才插，整节课最多 3 张，剪藏时缩到 960 宽并压缩。

课程重点和查漏补缺

  • AI 区「课程重点」页点「生成课程重点」。不套固定栏目，按老师这节课实际的知识体系组织；只写老师讲过的，不补充、不评价；定义、口诀、规则、数字照录，每条标出处时间（点时间跳过去）。
  • 老师的自述（经历、学员数量、出版、原创声明）和课程安排（哪些放到后面的课、线下课讲）一律保留，每条标「老师自述：」，不评价、不删除。
  • 老师口述和课件不一致时两边分别写出，加「整理者注：口述与课件不一致」。
  • 拿不准的标「（存疑）」，老师提到但没讲明的标「（未讲明）」，不补写；字幕提前结束、最后一句没说完、视频结尾损坏，会写一行「整理者注」。
  • 查漏补缺：生成后默认自动进行（可在「设置 → 课程重点模板」里关掉），AI 对照完整字幕，把漏掉的内容补进对应小节。下方会显示「字幕被引用约 xx%」和没有出处的时间段。也可以随时点「查漏补缺」。
  • 重点待更新：课程重点是按生成时的字幕写的。之后你又改了 3 句以上字幕（比如回听改了存疑句），上方会出现提醒和「重新生成」按钮，媒体库也标「重点待更新」。存疑句多的课，建议改完再重新生成一次。
  • 可以点「编辑」直接改；剪藏时放在笔记上半部分。
  • 要求（模板）可以在「设置 → 课程重点模板」里改，每位老师也可以单独设一份。

AI 对话

  • AI 读过这节课的全部字幕和术语表，可以问任何内容；回答里的时间点可以点击跳转。
  • 下面的快捷问题：概括要点、解释难点、出复习题、整理方法、找识别错误。
  • 对话记录跟着这节课保存。

老师工作台（和老师对话）

把一位老师的全部课程蒸馏好以后，AI 就能按这位老师的知识和思路和你对话，像向老师本人提问一样。

怎么开始：蒸馏一位老师

  • 从媒体库的课蒸馏：左栏顶上切到「老师」，点人像加号按钮 →「从媒体库的课蒸馏一位新老师」（或在「课程」里右键一个文件夹 →「用这个文件夹的课蒸馏一位老师」）。填老师名字，选课所在的文件夹，勾选要用的课（要先生成字幕；有课程重点更好，不用先剪藏、不用先校对），点「开始蒸馏」。
  • 蒸馏做三步：① 逐节提取观点库：每节课单独让 AI 读完整字幕，把老师讲的拆成一条一条，每条带出处（第几节课第几分几秒）、标明是观点、方法还是定义，老师讲自己的经历和立场单独列；② 合并成「课程蒸馏」：老师的体系、核心观点、反复强调的、前后不一致的、没讲到的；③ 写「老师画像」：第一节是软件固定写的对话规则，后面是他的信念、思考顺序、反对什么、常用比喻、说话风格。课很多（几十节）时，第 ② 步会先分组小结再合并。
  • 写到哪里：Obsidian「04、外部知识转化库/01、老师分身蒸馏资料/老师名/」里的「01、观点库（逐节提取）」「02、课程蒸馏」「03、老师画像（对话用）」。这些是 AI 写的，状态标着「待作者审核」；属性里还写着「来源人工校对：几节 / 共几节」（老师普通话标准、识别准确的课可以不校对，可能识别错的地方会放进「存疑」）。AI 标的出处时间超出课程长度的标「时间待核对」，写了观点库里没有的编号的在文末列出来。
  • 在后台做：30 分钟的课实测大约 3 分半钟（几十节的大课要几个小时），用「对话」的 AI（ChatGPT 账号会占用额度）。对话区上方和左栏显示进度，可以照常看课；点「停止」或额度用完，做完的课都存着，右键老师「继续蒸馏」接着做，不重复花钱。
  • 老师出了新课：右键老师 →「更新蒸馏」，勾上新课。只提取新课和字幕改过的课，再重新合并、写画像。课程编号 S01、S02……一旦分配就不变，以前对话里的出处照样能点。
  • 覆盖前会问你：上次蒸馏之后你在 Obsidian 里改过这几份文件的，开始前会先问；每次覆盖前都整份备份到软件的「backups\蒸馏」（每位老师留 20 份）。

或者：导入已经蒸馏好的老师文件夹

  • 点人像加号按钮 →「导入已经蒸馏好的老师文件夹」，选「04、外部知识转化库/01、老师分身蒸馏资料」里的老师文件夹，里面要有「观点库」和「老师画像」两份文件（文件名里带这几个字）。软件会按观点库开头的「来源」表找到每篇课程笔记里记的视频，出处才能跳转；找不到视频的课会标出来。
  • Obsidian 里的观点库、老师画像以那边为准：你在 Obsidian 里改了，下一次提问就用改过的。

对话

  • 提问：下面输入框里打字，Enter 发送（Shift + Enter 换行），写的时候点「停止」可以停下。第一次打开有几个示例问题，点一下就问。
  • 出处：课程里讲过的内容带出处，例如 S02 19:54（第 2 节课 19 分 54 秒）或 S02-21（观点库第 2 节第 21 条）。鼠标停在出处上能看到那一秒前后的原话；点一下切到「课程」，打开那节课从那一秒开始播放。看完点左上角「老师」回到对话。观点库和课程里都找不到的出处会标成红色，那多半是 AI 编的，要小心。
  • 蓝色框「AI 推测」：课程里没讲的问题，AI 按老师讲过的原则推测他可能怎么看，不是课程内容。紫色框「AI 自己的看法」：只在你要求时才有，不代表老师。
  • ☆ 收藏：觉得好的回答点它下面的「☆ 收藏」，连同你的问题追加到老师文件夹里的「对话精选.md」（写之前会备份），按钮变成「★ 已收藏」。★ 收藏整个对话（对话区右上角）：这个对话里还没收藏的回答一次都收藏，已经收藏的不重复。对话精选：在 Obsidian 里打开收藏的内容。
  • 朗读：对话区右上角的「朗读」读老师的回答，用法和课程重点的朗读一样。

圆桌讨论（几位老师一起讨论一个问题）

  • 新建：左栏老师下面的「圆桌讨论 ＋ 新建」（或人像加号按钮里的「新建圆桌讨论」），勾选两位以上蒸馏好的老师。
  • 提问：每位老师只用自己的老师画像和课程资料各自回答，一位一位写出来；出处按是哪位老师说的来认，点了跳到他那节课那一秒。几位老师都答完，AI 自动写总结：共识、分歧和原因、各自的适用条件、还待验证的问题（总结是 AI 归纳的，不是任何一位老师的原话）。
  • 让老师们互相回应：每位老师看了别人的回答再回应一轮，仍然只能用自己课程里的内容，超出的标「AI 推测」，然后重新总结。「重新总结」只重写总结。
  • ★ 收藏到 Obsidian：选一个主题文件夹，整场讨论存进「04、外部知识转化库/02、主题蒸馏资料/那个主题/日期、问题、多位老师讨论.md」；以后再点就更新同一个文件（覆盖前备份）。
  • 每提一个问题调用 AI「老师人数 + 1」次。讨论记录保存在软件里；右键可以改名、删除。

主题蒸馏（写书时参考）

  • 新建：左栏「主题蒸馏 ＋ 新建」，填主题（例如「止损」），可以写想重点看什么，选结果放在哪个主题文件夹（交易认知、交易系统、分析技术、操作技术、执行力管理、跨主题综合），勾选两位以上老师。
  • 在后台做：先从每位老师的观点库里挑出和主题相关的条目和课程原文，AI 整理出「他关于这个主题讲了什么」；再合并成一份比较文档：一句话、每位老师怎么说、共识、分歧和原因、适用条件和边界、来源质量、还待验证的问题。写进「04、外部知识转化库/02、主题蒸馏资料/那个主题/日期、主题、跨来源蒸馏.md」。
  • 做好后在软件里也能看，出处写成 人间落叶 S02-21 这样，点了跳到那位老师那节课；对不上的出处标红，文末也列出来。右键可以重新蒸馏（覆盖前备份）、删除记录（Obsidian 里的文件不动）。

提示词

  • 对话区右上角的「提示词」：显示软件蒸馏和对话时交给 AI 的提示词原文（逐节提取、合并、写画像、对话、圆桌讨论、主题蒸馏）。知识库「02、规则体系/01、通用规则/08、AI蒸馏提示词」里也存了一份一样的。

对话记录

  • 每位老师可以有多个对话，都保存在软件里，左栏按时间列出；上面的搜索框能按标题和内容找。「新对话」开一个新的。
  • 右键对话：改名、删除。右键老师：更新蒸馏 / 继续蒸馏（软件里蒸馏的老师）、重新查找课程（笔记或视频挪了位置后）、在资源管理器中打开老师文件夹、清空全部对话、移除这位老师（只删软件里的记录，Obsidian 里的文件不动）。
  • 每次提问，软件会把老师画像、课程蒸馏、观点库和最相关的十几段课程原文一起交给「设置 → 任务用哪个 AI」里「对话」用的 AI（一次大约三万多字），用的是那个 AI 的额度。

一键整理

按顺序自动完成勾选的步骤：生成字幕 → AI 按术语表校对 → 挑必要的插图 → 用画面复核校对后还存疑的句子 → 翻译（英文课程）→ 课程重点（含查漏）→ 剪藏 → 找新术语（弹出来让你勾选）。某一步失败会停下来并告诉你原因，前面做完的步骤已经保存；「用画面复核存疑句」「查漏补缺」失败不影响后面的步骤。整理完建议检查一遍存疑句，打开「已校对」再剪藏。

单独点的整理按钮（生成字幕、AI 校对、课程重点等）做的时候，也可以切到别的课：任务在后台接着做，上方进度条写明是哪节课，做完会提示你；切回来时还没做完的话会接着显示进度。只有「AI 写图片说明」「AI 重画」「AI 读目录分章」这几个短任务要等它做完再切。

整理时可以切到别的课：点「开始」后，这节课交给后台整理，你马上可以打开别的课听课、校对。上方的「后台整理」条显示整理到哪了，点它可以看排着的课、停下某一节；媒体库里标「整理中 xx%」「排队中」。在媒体库右键一节课选「排进后台整理」，可以一次排好几节（按一键整理默认的步骤，只做还没做完的），一节一节接着整理。整理完会提示你；这节课正开着就直接显示结果，勾了「剪藏」或有新术语要勾选的，也在这节课开着时接着做。最好整理 A 课、校对 B 课；你在正被整理的课里改了东西，保存时会先问你要哪一份。软件完全退出时（不是点 × 收到托盘），没整理完的会停下，做完的步骤已经保存，下次再点一键整理会接着做。

让 AI 在后台自动整理：也可以让 Claude Code、Codex 这类 AI 助手调用猛人学习，替你做一键整理（不剪藏，用法见软件开源页的「命令行」说明）。它和这里的一键整理是同一套流程，整理好的课在媒体库里点刷新就能看到。你正开着的课如果被后台整理了，打开时会提示；保存时会先问你要后台整理的结果还是你自己的版本，不会互相覆盖。

下载字幕

顶栏「下载」：TXT 或 SRT；可以选中英对照、只要原文或只要中文；TXT 可以选带不带时间戳。

剪藏到 Obsidian

  • 点顶栏「剪藏」。笔记结构：属性（视频文件、人工校对、剪藏时间、tags。tags 是 Obsidian 固定的，保持英文）→ 标题（下面不写老师、系列、时长；老师和归类请在 Obsidian 里自己处理，自己加的属性重新剪藏会保留）→ 课程重点（含必要的插图）→ 来源情况 → 完整带时间戳的字幕（存疑句会标出）。不附画面记录，笔记只有课程重点和完整字幕。
  • 存放位置：「设置 → Obsidian」里的文件夹，按老师分子文件夹；文件名格式可以设置（比如 {title}（猛人学习））。插图放在笔记旁边的 image 文件夹。
  • 同一节课再剪藏会更新原来那篇笔记——你在 Obsidian 里移动或改名了也能找到；软件不写「状态」（以前给交叉审核用的，已经不需要）；你自己在 Obsidian 里加的属性（比如状态、老师）重新剪藏都会保留。
  • 在 Obsidian 里加自己的内容，重新剪藏不会丢：重新剪藏只更新软件负责的部分（属性里软件写的那些、「## 课程重点」「## 完整字幕」两节），下面这些原样保留：
    • 自己加的小节：新起一行写 ## 我的笔记（名字随意，只要不叫「课程重点」「完整字幕」），放在哪里都行；
    • 写在课程重点或字幕里面的「标注」：在某条要点下面新起一行，写 > [!note] 我的理解，下一行写 > 你的理解……（每行都以 > 开头）。重新剪藏时它跟着上面那条要点走；那条要点没了，就挪到这一节最后；
    • 自己加的属性、标签（tags）、状态。
    直接改「课程重点」「完整字幕」里软件写的文字，重新剪藏会被覆盖——要改这些，请在软件里改。
  • 如果这篇笔记上次剪藏后在 Obsidian 里改过，剪藏前会先问你；确认后旧笔记先备份到 %APPDATA%\猛人学习\backups\笔记 再覆盖。剪藏后又在软件里改了字幕或课程重点，媒体库会显示「待更新剪藏」。

书籍和文档整理

  1. 在媒体库里点要整理的书或文档：PDF、Word（.docx / 老版 .doc）、电子书（EPUB、MOBI、AZW3）、演示文稿（PPTX / 老版 .ppt，一张幻灯片算一「页」）。TXT / Markdown 用「打开」。扫描或拍照的 PDF（每页是整张图片）点目录列的「识别文字（OCR）」：用 Windows 自带的文字识别在这台电脑上把每页认成文字，不联网、不花钱，300 页大约 1.5 分钟；原文件挪进同一文件夹的「_OCR前的原件」，确认没问题可以删。别的软件识别得很差的，可以点「重新识别文字」。有 DRM 加密的电子书（书店买的加密书）读不了，软件会提示。老版 .doc / .ppt 读不出标题层级，章节分得不对就点「AI 读目录分章」或手动改。
  2. 书分三列：左边「原书」（PDF 或文字版，「朗读原文」会读这一章的文字），中间「目录」，右边「整理笔记」；每一列都能点「隐藏」收成一条竖条、拖分隔线调宽度，「放大」让笔记占满。先在目录里核对：
    • 书名、作者（在「书籍信息」里）；
    • 「书上第 1 页是 PDF 第几页」：软件会自动认书上的页码，认不出时手动填，否则锚点写成「PDF 第 X 页」；
    • 章节分得对不对：和原书目录一致，前言、各部分的开篇、每一章、附录都单独一篇，按部分分组；可以直接改章名和起止页、加一章、删一章，或点「AI 读目录分章」。前言、目录不编号。
  3. 勾选章节点「整理选中的章节」，或「整理全部未整理的」。每章写一份提炼笔记：
    • 篇幅约原文的 1/5，开头一句话说这一章回答什么问题；
    • 按这一章自己的逻辑分几个小标题，不设固定栏目；留核心观点和结论、作者的原话定义、代表性的例子，能照着做的方法集中写在最后「照着做」；
    • 每个小标题标一次书上的页码（P42），点页码左边就跳到那一页；拿不准的句子标「（存疑）」；
    • 有图表的页截成图片给 AI 看；PDF 旁边有同名 Word（WPS OCR 导出的）时自动拿它当正文参考；外文书的笔记也用中文写；
    • 每章挑最关键的 1～2 张原书的图（形态、结构、流程、案例走势、关键表格）插进去；整理笔记里直接显示图，点图看大图；AI 看不准图的位置时用整页。
  4. 「整理笔记」切到「AI 对话」：可以「问这一章」（AI 读这一章的原文全文和笔记）或「问整本书」（AI 读全部章节笔记，再从原文里挑相关的页）。回答标页码，点了原书跳过去。
  5. 点「全书总览」生成「00、全书总览」，再点顶栏「剪藏」：写进 Obsidian 的 《书名》作者/ 文件夹。重新剪藏和视频笔记一样：你在 Obsidian 里自己加的小节（例如 ## 我的笔记）、写在要点下面的标注（> [!note] 我的理解）、属性和标签都会保留；直接改了软件写的小节，剪藏前会先问你，确认后先备份再更新。
  6. 可以在「设置 → Obsidian」里关联知识库里的《外部书籍与文档整理规范》，整理时作为补充参考（和软件的提炼要求冲突时以软件为准）。

数据和隐私

  • 字幕、课程重点、插图说明、对话、历史版本：存在视频旁边的 视频名.mp4.猛人学习.json；书籍的整理结果存在文档旁边的 书名.pdf.猛人学习.json。删了就没了。改名前的 .猛人字幕.json 照样能读，下次保存时自动改名。
  • 设置、API 密钥、ChatGPT 登录、老师档案、媒体库、播放进度：在 %APPDATA%\猛人学习\，都很小。不要删；换电脑用「导出设置」。
  • 整理任务记录（每次整理每一步做得怎样、出错的原因，最多留 300 条）：在 %APPDATA%\猛人学习\tasks\，可以删。
  • 缓存（转换后的视频、抽出的音频、关键帧截图、书籍页面图）和日志：在软件文件夹里的「缓存（可随时删除）」「日志（可随时删除）」，可以随时删，会自动清理：音频 3 天、截图和转换后的视频 30 天没用就删，转换后的视频最多留 5GB。「设置 → 关于与数据」里能看到占了多少，也能一键清空。
  • 软件没有服务器，不收集任何数据。音频只发给你选的识别服务，字幕、截图、书页只发给你选的 AI 服务。密钥只存在这台电脑上，日志里不记录密钥。

常见问题

视频打不开、没有画面？
常见格式（mp4、mkv、webm、mov，包括 YouTube、B 站下载的）都能直接放。flv、ts、avi 这类外壳第一次打开时换一下外壳，几秒钟；画面是 H.265（B 站高画质、抖音、苹果手机常见）、rmvb、wmv 这类，第一次打开要转换，等进度条走完，之后再打开就不用等了。转换要用 ffmpeg：下载的压缩包里已经带了（软件文件夹里的 ffmpeg 文件夹），不要删；如果删了，在终端运行 winget install Gyan.FFmpeg 安装。
保存时提示「这节课刚刚被后台的自动整理更新了」？
你开着这节课的时候，AI 助手在后台整理了它。选「确定」重新打开，看后台整理的结果（你刚才没保存的修改会丢掉）；选「取消」保留你现在的版本，覆盖后台的结果。
提示「还没有填写 API Key」「鉴权失败」？
到「设置」对应的服务里填好，点「测试连接」。ChatGPT 账号登录过期时重新登录。
国外的服务连不上？
「设置 → 网络代理」里填代理地址，并勾选那个服务的「通过网络代理连接」。
术语还是识别错？
把常错的词加进术语表（或在 Obsidian 的术语表里补上），再「AI 校对」；剩下的看「存疑」逐句回听修改。
书籍的页码不对？
改右边的「书上第 1 页是 PDF 第几页」。章节不对就改起止页，或点「AI 读目录分章」。
软件卡住、报错、关不掉？
「设置 → 关于与数据 → 打开日志文件夹」，把 app.log 发给 Claude 或维护的人看（后台自动整理的日志是 agent.log）。

缓存和日志放在哪里

默认放在软件所在的文件夹里，文件夹名就写着「可随时删除」，不占 C 盘。更改后重启软件生效。

软件出问题时（报错、卡住、关不掉），日志里会记下原因。把日志文件夹里的 app.log 发给 Claude 就能查。日志不包含 API Key。设置、老师档案和媒体库很小，放在下面「设置」那个文件夹里。
