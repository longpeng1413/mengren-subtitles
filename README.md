# 猛人学习（Mengren Learning）

> 作者：longpeng1413 和 Claude

一个 Windows 上的学习资料整理软件：
- **视频 / 音频课程**：准确识别字幕，按老师的术语表校对，提炼课程重点，只在必要的地方插图；剪藏到 Obsidian，得到一篇可以直接用来做知识整理或「蒸馏」的笔记：上半部分是课程重点，下半部分是完整的带时间戳的字幕。
- **书籍和文档**（PDF、Word .docx / .doc、电子书 EPUB / MOBI / AZW3、演示文稿 PPT / PPTX、TXT、Markdown）：按原书目录分章，每章写约原文 1/5 的提炼笔记（核心观点、照着做清单、原话定义、代表性例子），可以对一章或整本书问 AI（AI 读原文回答），原文能朗读，最后生成全书总览，剪藏到 Obsidian。

![猛人学习界面](docs/screenshot.jpg)

## 下载和安装

1. 到 [Releases](https://github.com/longpeng1413/mengren-learning/releases) 下载最新的 `mengren-learning-版本号-windows-with-ffmpeg.zip`，解压到任意文件夹（不要放在 C:\Program Files 这类需要管理员权限的地方）。压缩包已经附带 ffmpeg（用来读取和转换音视频），不用另外安装。
2. 双击 `猛人学习.exe`。整个文件夹要放在一起，不能只拷 exe。
3. 程序没有数字签名，第一次打开时安全软件可能会提示，选择允许即可。

**换电脑 / 解压即用**：在旧电脑「设置 → 关于与数据」里「导出设置」，把得到的 `猛人学习设置.json` 放进新电脑的软件文件夹（和 `猛人学习.exe` 放在一起），第一次启动时会自动导入，导入后文件会改名为「…（已导入，可删除）」。

从「猛人字幕」升级：设置、老师档案、媒体库会自动搬到新名字下；视频旁边旧的 `.猛人字幕.json` 照样能读，下次保存时自动改成 `.猛人学习.json`。

运行环境：Windows 10 / 11（64 位）。界面用的是系统自带的 Edge WebView2，Windows 11 已内置；Windows 10 如果打不开，请先安装 [WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)。

## 第一次使用

1. 点右上角的齿轮打开「设置」，至少设置一个**字幕识别服务**和一个 **AI 服务**，每个服务都有「测试连接」按钮：
   - 中文课程识别：豆包语音（火山引擎）或硅基流动；
   - 英文课程识别：OpenAI Whisper；
   - AI 校对、翻译、课程重点、对话：ChatGPT 账号登录、Claude、Gemini、DeepSeek、豆包大模型、硅基流动、OpenAI 任选。
2. 在「设置 → Obsidian」里选择你的库和要存放的文件夹。
3. 在「设置 → 老师与术语表」里给常听的老师建一份术语表（可选，但对识别准确率帮助很大）。
4. 在左侧媒体库点「＋文件夹」，把课程文件夹加进来，点哪个看哪个。

## 典型用法

1. **建老师档案**：给每位老师建一份术语表；整份术语说明文档可以用「从文件导入…」放进「术语说明」。
2. **加媒体库**：把一位老师的课程文件夹加进来；在文件夹的「⋯」菜单里绑定这位老师，里面的视频会自动用他的术语表。
3. **一键整理**：点开一节课，点「一键整理」，按顺序执行：
   - 生成字幕（术语表会传给识别服务）；
   - AI 按术语表校对（拿不准的句子标成「存疑」，不乱改）；
   - 挑必要的插图（走势图、K 线标注、老师手绘，需要能看图的 AI）；
   - 用画面复核存疑句：截下每句存疑句说话时的画面（常有烧录字幕），能确认的改正，看不清的留给你回听；
   - 翻译（英文课程）；
   - 生成课程重点，再自动「查漏补缺」。
4. **人工检查**：点字幕栏上方的「存疑」逐句回听；在右边字幕上直接修改，改完自动保存；检查完打开「已校对」。
5. **剪藏**：笔记存到 Obsidian 库的 `猛人学习/老师名/课程名.md`（文件夹可以设置）。

## 书籍和文档

1. 在媒体库里点要整理的书或文档（PDF、Word、EPUB、MOBI、AZW3、PPT / PPTX；TXT / Markdown 用「打开」）。扫描或拍照的 PDF（每页是整张图片）点目录列的「识别文字（OCR）」：用 Windows 自带的文字识别在本机把每页认成文字，不联网、不花钱，300 页大约 1.5 分钟，原文件挪进同一文件夹的「_OCR前的原件」；有 DRM 加密的电子书读不了。
2. 三列：左边「原书」（PDF 或文字版，可以朗读原文），中间「目录」，右边「整理笔记」；每一列都能单独隐藏、拖宽度。先在目录里核对：书名、作者、「书上第 1 页是 PDF 第几页」（软件会自动认书上的页码），以及章节分得对不对。章节和原书目录一致：前言、各部分的开篇、每一章、附录都单独一篇，按部分分组；分得不对可以直接改章名和起止页，或者点「AI 读目录分章」。
3. 勾选章节点「整理选中的章节」，或「整理全部未整理的」。每章写一份**提炼笔记**（2026-10-29 起，以前的「完整转写」比原文还长）：
   - 篇幅约原文的 1/5（最多 1/4），开头一句话说这一章回答什么问题；
   - 按这一章自己的逻辑分几个小标题，不设固定栏目；留核心观点和结论、作者的原话定义、代表性的例子，能照着做的方法集中写在最后「照着做」；
   - 每个小标题标一次书上的页码（P42），点页码左边就跳到那一页；拿不准的句子标「（存疑）」；
   - 有图、表的页截成图片一起交给 AI 看（需要能看图的 AI）；PDF 旁边有同名的 Word（WPS 做 OCR 后导出的）时自动当正文参考；
   - 外文书的笔记也用中文写，术语附原文；
   - 每章挑最关键的 1～2 张原书的图（形态、结构、流程、案例走势、关键表格）插进去，整理笔记里直接显示图，点开放大；AI 看不准图的位置时用整页。
4. 「整理笔记」这一列切到「AI 对话」，可以「问这一章」（AI 读这一章的原文全文和笔记）或「问整本书」（AI 读全部章节笔记，再从原文里挑相关的页）。回答标页码，点了原书跳过去。笔记写得短不影响问答：细节和原话从原文里来。
5. 点「全书总览」生成 `00、全书总览`（一句话、全书主线、各章导航、最值得记住的、照着做），再点「剪藏」：写进 Obsidian 的 `《书名》作者/` 文件夹（`00、全书总览.md`、`01、第一章 ….md`、`image/`）。重新剪藏和视频笔记一样，保留你在 Obsidian 里加的小节、标注和属性。
6. 可以在「设置 → Obsidian」里关联知识库里的《外部书籍与文档整理规范》，整理时作为补充参考（和软件的提炼要求冲突时以软件为准）。

## 功能

- **媒体库**（左侧，可以收起，宽度可以拖动）：
  - 可以加多个文件夹和单个文件，点哪个看哪个；文件夹**按实际层级显示**，每一层都能展开、收起、绑定老师（没绑定的沿用上一层）；
  - 排列：最上层按加入先后；文件夹里带序号的按序号、没序号的按下载时间，**按住拖动**可以调整顺序（带序号的拖乱了会提示改名）；
  - 先加了子文件夹、又加上层，会问你要不要合并；
  - 文件夹「⋯」菜单「整个文件夹排进后台整理…」：定好一套规则（做哪几步、老师、豆包模型和账号），把文件夹（含子文件夹）里还没整理完的课一节一节排进后台；规则记在文件夹上，下次带出来，以后右键单节课「排进后台整理」也按它；额度用完时这一批剩下的自动停下；
  - 文件夹「⋯」菜单「这里的课不写课程重点」：适合灵修类这种逐字稿课程，只识别、校对，直接蒸馏老师。一键整理默认不勾课程重点，后台整理和命令行跳过，也不会因此标「未整理完」；下层文件夹沿用，可以单独改回；
  - 右键「重命名」：电脑上的文件 / 文件夹、字幕记录、播放进度一起改；已经剪藏的 Obsidian 笔记保留原文件名；
  - 每个视频会标出：有没有字幕、有没有重点、是否已校对、是否已剪藏，以及看到哪里。
- **续播**：每个视频都会记住播放进度，再打开时从上次的位置接着播。
- **各平台的视频格式都能放**：YouTube（mkv / webm，AV1、VP9）、B 站（mp4 / flv，含 H.265、AV1）、抖音 / 视频号、网课（ts / m3u8 下载）、录屏（mkv / flv）、网盘老资源（avi、rmvb、wmv、mpg、vob）、摄像机（mts / m2ts）、苹果设备（mov / m4v），以及常见音频。能直接放的直接放；只是外壳不认的，几秒钟换个外壳；只有画面编码本身放不了（例如 H.265、rmvb）才转换，第一次打开时等一会儿。
- **字幕**：
  - 点文字跳转，并可直接编辑；点时间只跳转；
  - 鼠标移到某句上，可以对齐时间、拆分、合并、删除，都可以撤销；
  - 可以搜索，可以单句循环（开着时开关旁边写明在循环哪一句，换一节课自动关掉），可以在画面上叠加字幕；
  - 字幕栏上方「插入截图」：把视频现在的画面插在正在播放的这一句后面；语音识别断句不准时，点图下面的「上移 / 下移」挪到对的句子后面，也能裁剪、调大小（见下面「插图」）；剪藏时放进笔记「完整字幕」对应的那一句下面；
  - 重新识别、AI 校对、清空、恢复之前会自动存历史版本（最多 5 份），随时可以换回来；
  - 整理的某一步做到一半出错（网络断了、AI 返回不对），这一步什么都不写，字幕保持原样，不会出现「改了一半」。
- **文字设置（字幕栏右上角的「Aa」）**：字号、行距、句间距、字幕栏宽度、字体和主题。
- **布局**：视频、字幕、AI 区之间的分隔条都可以拖动；AI 区可以放在视频下方，也可以移到最右侧当侧边栏，还可以一键放大或隐藏。
- **课程重点**：不套固定栏目，按老师这节课实际的知识体系和逻辑框架来组织，可以调整顺序、合并同一件事。只写老师讲过的内容，不补充、不推测、不评价；定义、口诀、规则、数字照录，每个要点标时间戳，拿不准的标「存疑」。老师的自述（经历、学员数量、出版、原创声明）和课程安排一律保留，标「老师自述：」，不评价、不删除；老师口述和课件不一致时两边分别保留并加「整理者注」；老师没讲明的标「（未讲明）」，不补写。要求可以改，每位老师也可以单独设一份。
- **插图（画面）**：识别画面只为一件事——给课程重点配上必要的图。AI 区的「画面」页点「找插图」：
  - 软件每隔约 15 秒截一张候选画面（避开老师挡住屏幕的那几秒），老师说「大家请看」时也截一张；
  - 能看图的 AI 只留光看文字不好理解的（走势图、K 线标注、老师手画的曲线和结构图），纯文字课件、标题页都不要；每张写一句说明；
  - 太多时再去掉重复的、被老师挡住的，最多留 8 张候选；
  - 课程重点只在文字确实说不清的地方插图，整节课最多 3 张，图片缩到 960 宽并压缩，让知识库尽量小；
  - 看到重要画面可以点「截取当前画面」；
  - 也可以自己往课程重点里插图：课程重点下面点「插入截图」，把视频现在的画面插在出处时间最接近的那一条重点后面（正在编辑时插在光标那一行后面）；图下面「上移 / 下移」调整位置、「删除」去掉，AI 插的图也能这样挪；手动插的图「重新生成」课程重点后会自动放回去；
  - 字幕栏和课程重点里的截图下面都有「✂ 裁剪」和「⇲ 大小」：裁剪是在截图上拖出要留下的部分（比如竖屏视频只留中间的课件），原截图不会被改，随时可以恢复整张；大小是拖滑块（或点小 / 中 / 大 / 自动）调这张图显示多大，图马上跟着变，也可以让这节课的图都用同一个大小。软件里、打印和剪藏到 Obsidian 的笔记里都是这个样子；
  - **AI辅助理解图**：要插的图如果画面本身看不清（PPT、板书模糊或被挡住），AI 依据老师的讲解和画面里能看清的部分重画一张——结构、流程类画成流程图，走势、K 线、曲线类画成矢量图，剪藏时代替截图并标注「AI辅助理解图｜根据老师讲解和画面整理，非原画面」；只画老师讲过、画过的，拿不准就不画。也可以对单张点「AI 重画」或「改用原截图」。
- **打印课程重点**：AI 区右上角「朗读」旁边的「打印」，只打印课程名和课程重点（连同插图），文字黑色、图片保持原色（打印窗口里「颜色」选彩色或黑白）；也可以选「另存为 PDF」。
- **查漏补缺**：课程重点生成后，AI 再对照完整字幕检查一遍，把漏掉的内容补进对应小节；界面上显示字幕被引用的比例和没有出处的时间段。
- **重点待更新**：课程重点是按生成时的字幕写的。之后你又改了 3 句以上字幕（比如回听改了存疑句），课程重点上方会提醒你重新生成，媒体库也标「重点待更新」，点一下就用改好的字幕重新写。
- **来源情况**：字幕提前结束、最后一句没说完、视频结尾损坏，软件会自己检查出来写进笔记，不让 AI 补写。
- **存疑句**：AI 校对时读起来不通、疑似听错的句子，用橙色标出并写明原因；点「存疑」逐句跳过去单句循环回听。
- **AI 对话**：AI 读过全部字幕和术语表，回答里的时间点可以点击跳转。
- **老师工作台（和老师对话）**：左栏顶上切到「老师」。
  - **蒸馏一位老师**：从媒体库选这位老师的课（有字幕就行），AI 在后台逐节把老师讲的拆成「观点库」（每条带出处：第几节课第几分几秒，分观点、方法、定义，老师的自述单独列，有疑问的标出来），再合并成「课程蒸馏」（体系、核心观点、反复强调的、前后不一致的、没讲的），写出「老师画像」（对话规则、信念、思考顺序、常用比喻、说话风格），写进 Obsidian「04、外部知识转化库/01、老师分身蒸馏资料/老师名/」。中途停了接着做；老师出了新课只提取新课。也可以导入已经蒸馏好的老师文件夹。
  - **对话**：AI 按老师画像，用这位老师的知识和说话方式回答，讲过的都带出处，点出处跳到那节课那一秒；课程没讲的标「AI 推测」。多个对话保存在软件里、可以搜索；好的回答（或整个对话）收藏进 Obsidian 的「对话精选」。
  - **圆桌讨论**：就一个问题请几位老师一起讨论。每位老师只用自己的课程各自回答（出处可点），AI 再总结共识、分歧和各自的条件；还可以让老师们看了别人的回答再互相回应一轮。好的讨论整场存进 Obsidian 的「02、主题蒸馏资料」。
  - **主题蒸馏**：选一个主题（比如「止损」）和几位老师，后台从每位老师的观点库里找出相关内容，比较他们分别怎么说（共识、分歧和原因、条件和边界、还待验证的），写进「04、外部知识转化库/02、主题蒸馏资料」，写书时参考。
  - **提示词**：软件蒸馏和对话时交给 AI 的提示词原文，在软件里能直接看，Obsidian 规则体系里也存了一份。
- **下载字幕**：TXT 或 SRT，可以选中英对照、只要原文或只要中文。
- **剪藏到 Obsidian**：属性（视频文件、人工校对、剪藏时间、tags）→ 标题。不写老师、系列、时长：老师和归类在 Obsidian 里自己处理，自己加的属性重新剪藏会保留→ 课程重点（含插图）→ 完整带时间戳的字幕（存疑句会标出；你在字幕栏用「插入截图」手动插的画面，放在对应那一句下面）。不附画面记录。插图复制到笔记旁边的 `image` 文件夹。重新剪藏只更新软件负责的部分（软件写的属性、「课程重点」「完整字幕」两节）：你在 Obsidian 里自己加的 `## 小节`、写在要点下面的标注（`> [!note] 我的理解`）、属性和标签都会保留；直接改了课程重点或字幕的文字，剪藏前会先问你，确认后先备份再覆盖。同一节课再次剪藏会更新原来的笔记，即使你在 Obsidian 里移动或改名了；笔记里的 status 会保留。文件名格式可以设置。
- **主题**：墨黑（默认）、帝王紫、深灰、浅色，另有 7 种强调色。
- **点右上角 ×**：默认收到屏幕右下角的托盘，不退出（单击托盘图标打开，右键「退出」）；「设置 → 关于与数据」里可以改成直接退出。
- **换电脑**：设置可以导出成一个文件，在新电脑上导入。

## 术语表

术语表每行一条，有三种写法：

```
峰级, 峰级线, 破级          ← 专用术语（传给识别服务当热词）
风级, 风机 => 峰级          ← 常见识别错误：交给 AI 结合上下文判断，不直接替换
托破旋 =>! 拓扑学           ← 确定不会误伤的：识别完直接替换
```

单字或常用词（比如「分 => 峰」）一定不要加感叹号，否则「部分」也会被改成「部峰」。整份术语说明文档放在「术语说明」框里，只给 AI 参考，不传给识别服务。

**推荐：直接关联 Obsidian 里的术语表文件。** 在老师档案里点「关联术语表文件」选中那份 MD，软件每次都读最新内容：
- 第一列表头是「术语」的表格、小节里写了「正确写法 / 标准写法」的词、`--hotwords "…"` 里的热词，当作术语传给识别服务；
- 表头含「ASR / 误识 / 识别」的表格（左列错写、右列正确写法），当作识别错误参考，只交给 AI 结合上下文判断；
- 第一列表头含「直接替换」的表格（左列错写、右列正确写法），识别完直接替换，等于 `错写 =>! 正确`，只放确定不会误伤的长词；
- 整份文件给 AI 当术语说明。

以后只需要在 Obsidian 里改术语表。

**逐课积累术语表。** 「课程重点」页的「新术语」按钮（一键整理的最后一步也会做）：AI 从这节课的校对改动（AI 改的、看画面改的、你手动改的）和完整字幕里，找出术语表还没有的新术语和识别错误，弹出来让你勾选、改字、点时间回听；只有确认的才加进去。关联了文件时写在文件末尾的「逐课补充（猛人学习）」一节（两张表：新术语、识别错误），文件其他内容不动，写之前自动备份到 `%APPDATA%\猛人学习\backups\术语表`；只记名称，不写定义。课上得越多，术语表越完整。

| 环节 | 做法 |
|---|---|
| 识别（豆包） | 术语作为热词传给豆包；没有术语时，传老师和课程背景 |
| 识别（OpenAI Whisper） | 术语写进提示词 |
| 识别（硅基流动） | 接口读不了术语表，靠后面的 AI 校对 |
| 识别完成后 | 只有 `错写 =>! 正确` 的对照直接替换 |
| AI 校对 | 参考术语表、识别错误对照和术语说明，结合上下文只修正识别错误，不改写句子；改过的句子用绿色下划线标出，可以撤销 |
| 翻译、课程重点、对话 | 都会参考术语表和老师背景 |

## 字幕识别服务

| 服务 | 说明 |
|---|---|
| 豆包语音（火山引擎） | 中文最准，带逐句时间戳。只用四种模型，按顺序自动换：流式识别 2.0（识别最准）→ 录音文件识别 1.0 极速版 → 录音文件识别 1.0 标准版 → 录音文件识别 2.0 标准版。可以填好几个账号，额度用完自动换下一个。新版控制台用 API Key，旧版用 App ID + Access Token |
| 硅基流动 | 有 Qwen3-ASR、SenseVoice 等模型。只返回文字、不返回时间，软件会按停顿切成短段，时间可能差几秒 |
| OpenAI | whisper-1 带逐句时间戳，适合英文。国内访问需要在「设置 → 网络代理」里填代理 |

## AI 服务

| 服务 | 怎么接入 | 适合做什么 |
|---|---|---|
| ChatGPT | 用 ChatGPT 账号登录（Plus / Pro / Business），调用套餐里的 Codex 额度，不花 API 费用 | 课程重点、对话 |
| Claude | API Key。Anthropic 不允许第三方软件用 Claude.ai 账号登录 | 课程重点 |
| Gemini | AI Studio 的 API Key（有免费额度）。Google 不允许第三方软件借用账号登录 | 通用 |
| DeepSeek | API Key | 校对、翻译，便宜 |
| 豆包大模型（火山方舟） | API Key，和「豆包语音」是两个不同的服务 | 中文 |
| 硅基流动 | 和识别用同一个 Key | 校对、翻译 |
| OpenAI | API Key | 通用 |

课程重点和对话、AI 校对、翻译、画面识别可以在「设置 → 任务用哪个 AI」里分别选用不同的服务。画面识别要能看图：ChatGPT 账号、Claude、Gemini、OpenAI 都可以，豆包大模型和硅基流动要选视觉模型，DeepSeek 不能看图。

ChatGPT 账号登录用的是 OpenAI Codex 命令行工具的登录方式，不是 OpenAI 为本软件提供的正式接口，以后可能会变化。

## 数据和隐私

| 内容 | 位置 | 能不能删 |
|---|---|---|
| 字幕、课程重点、插图说明、对话记录、字幕历史版本 | 视频旁边的 `视频名.mp4.猛人学习.json` | 删了字幕就没了 |
| 书籍的章节整理稿和全书总览 | 文档旁边的 `书名.pdf.猛人学习.json` | 删了整理结果就没了 |
| 设置、API 密钥、ChatGPT 登录、老师档案、媒体库、播放进度 | `%APPDATA%\猛人学习\`（都很小） | 不要删；换电脑用「导出设置」 |
| 整理任务记录（每次整理每一步的结果、出错原因，最多留 300 条） | `%APPDATA%\猛人学习\tasks\` | 可以删 |
| 老师工作台的对话记录、每节课的蒸馏结果 | `%APPDATA%\猛人学习\mentors\` | 不要删（在软件里可以删对话、移除老师）；观点库、老师画像在 Obsidian 里 |
| 圆桌讨论记录、主题蒸馏记录 | `%APPDATA%\猛人学习\roundtables\`、`topics\` | 不要删（在软件里可以删）；收藏和蒸馏好的文件在 Obsidian 的「02、主题蒸馏资料」里 |
| 覆盖前的备份（对话精选 30 份、蒸馏结果每位老师 20 份） | `%APPDATA%\猛人学习\backups\` | 可以删 |
| 缓存（转换后的视频、抽出的音频、关键帧截图） | 软件文件夹里的 `缓存（可随时删除）` | 可以随时删除（截图需要时会重新截） |
| 日志 | 软件文件夹里的 `日志（可随时删除）` | 可以随时删除 |

- 软件没有服务器，不收集任何数据。音频只会发给你选择的识别服务，字幕只会发给你选择的 AI 服务。
- API 密钥只保存在本机，日志里不记录密钥。
- 缓存自动清理（软件启动时、命令行整理前）：抽出的音频保留 3 天，转换后的视频 30 天没打开过就删（总量最多 5GB），关键帧截图 30 天没用过就删。日志最多 4 个文件、每个 2MB。缓存和日志的位置可以在「设置 → 关于与数据」里更改，也可以在那里一键清空缓存。

## 让 AI Agent 自动整理（命令行）

从源码运行时，可以让 Claude Code、Codex 这类 AI Agent 直接调用猛人学习整理课程，不用点界面。软件里的整理按钮和 Agent 用的是同一套后台流程，结果完全一样。做的事和在软件里点「一键整理」一样：生成字幕 → AI 校对 → 挑插图 → 用画面复核存疑句 → 翻译（只有英文视频）→ 课程重点 → 查漏补缺 → 新术语。**不剪藏**：整理结果写在原来的字幕文件里，你在软件的媒体库里打开、人工校对后自己剪藏。

```bat
rem 某课程第 12 个视频
mengren.cmd process --course 峰级分析 --index 12 --json

rem 今天新增、还没整理的全部整理
mengren.cmd process --todo --since today --json
```

做到一半失败，再运行会从失败的那一步接着做，做过的步骤不重复花钱。完整说明见 [docs/命令行.md](docs/命令行.md)。

## 从源码运行

需要 Python 3.12 以上（开发用的是 3.14）和 ffmpeg。

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt

rem 运行
.venv\Scripts\python app\main.py

rem 后台测试（不联网，会用 ffmpeg 生成测试视频）
.venv\Scripts\python tests\test_backend.py

rem Agent 自动整理和命令行的测试（不联网，识别和 AI 用假的）
.venv\Scripts\python tests\test_agent.py

rem 媒体库（树形、排列、合并、改名）和电子书、老版 Word / PPT 的读取
.venv\Scripts\python tests\test_library.py

rem 各平台 56 种音视频格式在内置播放器里实际播放（会弹出一个小窗口）
.venv\Scripts\python tests\test_playback.py

rem 界面测试（会弹出一个窗口自动操作，1–2 分钟后关闭；加 --exe 测打包好的版本）
.venv\Scripts\python tests\run_ui_test.py

rem 打包：输出到 dist-next；关掉正在运行的猛人学习后，双击「更新到新版.bat」换进 dist
.venv\Scripts\python build.py
```

目录结构：

- `app\main.py`：程序入口，负责开窗口和关闭流程；
- `app\bridge.py`：界面调用后台功能的接口；
- `app\cli.py`：命令行，给 AI Agent 调用（项目根目录的 `mengren.cmd`）；
- `app\core\`：
  - `asr.py`：字幕识别；
  - `llm.py`：AI 调用（翻译、校对、课程重点、对话）；
  - `codex_auth.py`：ChatGPT 账号登录；
  - `library.py`：媒体库（树形显示、排列、拖动排序、合并、改名）；
  - `ebook.py`：电子书（EPUB、MOBI、AZW3）、老版 Word（.doc）、演示文稿（PPT / PPTX）的读取；
  - `doc.py`：字幕文件、导出和剪藏；
  - `media.py`：ffmpeg 处理；
  - `frames.py`：挑插图、用画面复核存疑句；
  - `glossary.py`：把确认的新术语写进术语表；
  - `book.py`：书籍和文档（读取 PDF / Word / 文本、分章、页码、整理、全书总览、剪藏）；
  - `config.py`：设置、老师档案、播放进度和存放位置；
  - `workflow.py`：任务层，命令行调用的「一键整理」各个步骤；
  - `tasks.py`：Agent 任务记录、错误分类、重试、取消；
  - `cache.py`、`log.py`、`jobs.py`：缓存清理、日志、后台任务；
- `app\web\`：界面（HTML、CSS、JavaScript）。

技术说明：界面用 [pywebview](https://pywebview.flowrl.com/)（Edge WebView2）显示，以 `file://` 加载，通过 pywebview 的 js_api 和 Python 后台通信，不开本地网络端口。这样做是因为有些安全软件和代理工具会干扰本机回环连接（127.0.0.1）。
